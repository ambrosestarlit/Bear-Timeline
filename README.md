# ⏱️ Starlit Timeline Editor v2.5.20

**アンカーポイント機能修正版**

## 🎯 v2.5.20 の修正

### 🔧 アンカーポイント機能の修正
- **問題**: 「クリックで調整」ボタンが機能しない問題を修正
- **原因**: 他のクリックイベントリスナー（スポイト機能など）との競合
- **解決策**: 
  - イベントキャプチャフェーズを使用して優先度を確保
  - `stopPropagation()` と `preventDefault()` でイベント伝播を制御
  - 各モード間の相互排他処理を追加
  - すべての一時的なクリックイベントに `once: true` オプションを追加
- **影響範囲**:
  - アンカーポイント設定機能
  - カラーキーのスポイト機能
  - 色抜きクリッピングのスポイト機能
  - パペットピン追加機能

## 🎯 v2.4.0 の新機能

### 🔍 高解像度プレビュー対応
線画がきれいに表示される高品質プレビュー

#### 改善点
- **CSSで画像レンダリング最適化**: `image-rendering: crisp-edges`を使用

ブラウザのデフォルト設定では線画がぼやけて見えることがありますが、CSSの最適化により鮮明に表示されます。

## 🎯 v2.3.8 の機能

### 🎭 色抜きクリッピング機能
参照クリップの指定色領域にのみクリッピングを適用する高度な合成機能

#### 使い方
1. **クリップAを選択**（エフェクトを適用するクリップ）
2. プロパティパネルの **🎭 色抜きクリッピング** セクションで「色抜きクリッピングを有効化」をチェック
3. **参照クリップ**（クリップB）を選択して「📌 参照クリップを設定」
4. **🎨 スポイト** ボタンをクリックして、参照クリップから色を取得
5. **許容値** スライダーで色の範囲を微調整
6. クリップAが、クリップBの選択色領域にのみ表示されます

#### 特徴
- ✅ **動画完全対応**: 参照クリップが動画の場合、各フレームに自動追従
- ✅ **連番完全対応**: 参照クリップが連番画像の場合、各フレームに自動追従
- ✅ **二値化イラスト最適**: アニメ原画の境界が二値化されたカラーイラストに最適
- ✅ **スムージング不要**: 高速処理で軽量動作
- ✅ **リアルタイムプレビュー**: 色の変化を即座に確認可能

#### 応用例
- キャラクターの影部分にのみテクスチャを適用
- 線画の内側にのみ別の映像を表示
- 特定色領域のみにエフェクトを限定
- アニメーション動画の色指定領域に動的なクリッピング

## 🚀 新機能の使い方

### カラーキー（色抜き）
1. クリップを選択
2. プロパティパネルの **🎨 色抜き** セクションで「色抜きを有効化」をチェック
3. **💧 スポイト** ボタンをクリックしてキャンバスから色を取得
4. **許容値** スライダーで色の範囲を調整
5. **選択色以外を表示** をチェックすると、選択色を透明にします
6. カラーキーで表示された部分にのみクリッピングが適用されます

### 複数選択
1. **Shift キー** を押しながらクリップをクリック
2. 複数のクリップが金色の枠で選択される
3. 空白をクリックで選択解除

### シーンにまとめる
1. クリップを複数選択（Shift + クリック）
2. 選択したクリップを **右クリック**
3. メニューから選択:
   - **✨ 新規シーンにまとめる**: 新しいシーン名を入力して作成
   - **📦 既存のシーンに移動**: 移動先のシーンを選択
